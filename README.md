# OEC — One-Eyed Cobra

> Development branch — Work in Progress

Lightweight machine-learning framework written in **C** for embedded and resource-constrained systems.

### Features
- Pure C
- Modular architecture
- CPU/SoC friendly
- Small and efficient models
- No external ML runtime

### Status
🚧 Under active development. API and architecture may change.

### Build
```bash
git clone -b dev https://github.com/halloweeks/one-eyed-cobra.git
cd one-eyed-cobra
```
